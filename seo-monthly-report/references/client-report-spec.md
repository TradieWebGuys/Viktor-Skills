# Client-Facing Report Specification

TWG-branded PDF. Positive, visual summary focused on wins, improvements, and opportunities. No red indicators, no negative trend callouts.

## Core Principle

Only compare with the previous period when there is a positive improvement. If a metric declined, show the current value without comparison. Never highlight declines.

## Sections (in order)

### 1. Executive Summary

Key metrics table. Show current values. Only show comparison when positive.

**Include:** GSC Clicks, GSC Impressions, Organic Sessions, Total Sessions, Total Keywords Ranked, Page 1 Keywords, Estimated Traffic Value, Google Rating + Total Reviews.

**Exclude:** GSC Average Position (shown in keyword section instead).

### 2. Search Console Performance

Top Pages by Clicks. Columns: URL, Clicks. No CTR, impressions, or position.

### 3. Google Analytics 4 — All Channels

- Channel breakdown table
- Top Performing Pages (sessions/traffic only — no conversions here)
- Only compare when positive

### 4. Conversion Events

**Only show:** Phone call clicks, email clicks, form submissions.
**Exclude:** page_view, scroll, session_start, and other generic events.

### 5. Keywords Ranking

- Top keywords on page 1 with position and search volume
- Top 10 keywords moving towards page 1 (positions 11–20, trending up)
- Visual table format with colour-coded position indicators

### 6. Backlinks Profile

**Only show:** Total Backlinks, Referring Domains, Dofollow Backlinks.
**Exclude:** Broken backlinks, spam score, first seen dates, domain rank.

### 7. Google Business Profile

- Call Clicks, Website Clicks, Direction Requests
- Search vs Maps Views, Profile Interactions
- Total Reviews, Average Rating
- Number of GBP posts actually published this month
- Recently published pages with links
- Only compare when positive
- Visual graphs where possible

### 8. AI/LLM Visibility

- Online brand mentions
- AI Overview appearances
- LLM visibility (ChatGPT, Gemini, Perplexity, Claude)
- Exact queries where the business appears
- Trend/growth metrics

### 9. Website Audit Score

Overall score (target 90%+). If genuine issues, mention briefly in "Next Month" section (canonicals, broken links, sitemap, robots.txt, llms.txt, AI optimisation).

### 10. Next Month To-Do's

Aligned with client's SEO strategy doc and STATE.md. Specific planned deliverables, not generic bullets. 5 key focus areas.
